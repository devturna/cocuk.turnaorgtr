# Turna Çocuk

Çocuklar için ücretsiz, reklamsız ve veri toplamayan bir boyama ve oyun portalı.

Yayın adresi: https://cocuk.turna.org.tr

## Durum

Faz 1 (boyama bölümü) geliştiriliyor. Tasarım kararları ve gerekçeleri:
[docs/tasarim/boyama-bolumu.md](docs/tasarim/boyama-bolumu.md)

## Çalıştırma

```bash
npm install
npm run dev
```
